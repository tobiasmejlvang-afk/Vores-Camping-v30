# Changelog – Vores Camping v30.3

## Overblik
- Bevarer personligt cover, app-logo, Ferie Vagt-status, Ferie Album-dias, statistik, oversigtskort, seneste besøg, bedst bedømte, ønskesteder og cykelruter.
- Ur/dato kan nu slås til eller fra separat.
- Aktuelt vejr i coverområdet kan nu slås til eller fra separat.
- Nedtælling til næste campingtur kan nu slås til eller fra separat.
- Vejrdata hentes ikke på Overblik, når vejrfunktionen er slået fra.

## Indstillinger
- Ny selvstændig sektion **Funktioner**.
- Generelt indeholder Appnavn, forsidetekster og næste campingtur.
- Forside indeholder coverbillede, synlige sektioner, rækkefølge, kompakt/normal/luftig visning og Ferie Album-dias.
- Funktioner indeholder Ur, Nedtælling og Vejrudsigten.
- Udseende indeholder Tema, Farver, Skalering, Størrelse på elementer, Kort, Menu, Faner, Bokse, Knapper og Ikoner.
- Menu kan sættes til kompakt, normal eller stor.
- Faner kan vises som bløde, understregede eller kompakte.
- Ferie Albummets forside-dias styres nu kun under Forside, så samme indstilling ikke ligger dobbelt.

## Kompatibilitet
- Samme state-key som v30-v30.2 bruges fortsat.
- Eksisterende campingdata, ferier, ruter, billeder og indstillinger migreres via standardværdier uden nulstilling.
- ORS- og MapTiler-nøgler er fortsat adskilt fra backupdata.
